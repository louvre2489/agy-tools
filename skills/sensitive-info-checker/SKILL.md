# Sensitive Info Checker Skill (`sensitive-info-checker`)

## 目的
GitコミットやGitHub等のリモートリポジトリへのプッシュによって誤って機微情報を記録・アップロードすることを阻止するため、対象リポジトリの現在のファイル群（Working Tree）および過去の全コミット履歴（Git History）を検査し、結果をターミナルへ出力します。
ユーザーから「コミットして」「プッシュして」等の指示を受けた際は、実行前に必ず本スキルで検査を行い、機微情報が検出された場合はコミット／プッシュを中断してユーザーへ報告・確認を行ってください。

---

## 検査ルール・ポリシー

1. **実行前提（Git管理リポジトリ限定）**:
   - 対象ディレクトリ（未指定時はカレントディレクトリ `.`）が Git 管理下（`git rev-parse --is-inside-work-tree`）である場合のみ実行します。Git管理外の場合はエラーを表示して処理を中断します。
2. **検査スコープ**:
   - **Working Tree**: 追跡中ファイルおよび `.gitignore` で除外されていない未追跡ファイル全体
   - **Git History**: 過去の全コミット履歴（`git log --all -p` の追加行全体）
   - **除外対象（検査結果に一切出力しないもの）**:
     - Gitのコミット履歴メタデータ（`Author:` / `Committer:` 等）に含まれるメールアドレスは機微情報として扱いません。
     - コード作者を示す署名・著作権表記・パッケージメタデータ（`@author`, `Author:`, `Copyright (c)`, `Signed-off-by:`, `Co-authored-by:`, `__author__`, `author_email`, `package.json` や `pyproject.toml` 等の `author`/`authors`/`maintainers` ブロック、コメント内の `<email@...>` 署名、`作成者:` 等）に記載されているメールアドレスは機微情報として扱わず無視します。**これらを検知した場合、`sensitive-info-checker` の検出結果（件数カウント・検出一覧テーブル・補足説明のすべて）には一切出力しないでください（「コード作者の署名ですが除外しました」等の報告も不要です）。**
     - `.gitconfig` ファイル（Working Tree 内および過去の Git コミット履歴内の両方）は検査対象外とします。
3. **検査対象の機微情報**:
   - **APIトークン／キー**: AWS, GitHub, Google Cloud, Slack, OpenAI, Anthropic, 汎用APIキー等
   - **シークレット / SSHキー**: PEM/OpenSSH秘密鍵ヘッダ、JWT/クライアントシークレット等
   - **パスワード**: ハードコードされたパスワード、DB接続URI内の認証情報（`user:pass@host`）
   - **個人情報 (PII)**:
     - 氏名（フィールド指定や文脈上の個人名）
     - 電話番号（固定・携帯・国際表記）
     - 住所（郵便番号・都道府県〜番地）
     - マイナンバー（12桁個人番号）
     - クレジットカード番号（Luhn検証付き）
     - IPアドレス（グローバルIPv4アドレス）
     - コード・設定ファイル内のメールアドレス
4. **マスキングポリシー（厳守）**:
   - 検出した機微情報の値をターミナルに出力する際は、二次漏洩を防ぐため**必ず先頭4文字のみを表示し、残りを `****` にマスク**してください（4文字以下の場合は全体を `****` とする）。平文のシークレットや個人情報をそのままターミナルに出力してはいけません。
5. **出力先**:
   - Artifactファイルは生成せず、**ターミナル（チャット応答）へ直接出力**してください。

## 実行手順（ワークフロー）

### Step 1: 専用検査スクリプトの実行
同梱されているスキャナを実行します（デフォルトはカレントディレクトリ `.`）。

```bash
python3 ~/.gemini/config/skills/sensitive-info-checker/scripts/scan.py [対象リポジトリパス]
```
（※ワークスペース内に直接存在する場合は `skills/sensitive-info-checker/scripts/scan.py` を指定しても構いません）

- 終了コード `0`: 検出なし
- 終了コード `1`: 機微情報の疑いがある項目を検出
- 終了コード `2`: Git管理下のリポジトリではない等の実行エラー（この場合、エラー内容をユーザーに伝えて終了する）

### Step 2: エージェントによる文脈精査（氏名・住所・ハードコード設定の確認）
スクリプトの正規表現だけでは捉えきれない文脈依存の個人情報（例：コメントやREADME、設定ファイル、テストデータ内にラベルなしで直接書かれた実在の個人氏名や住所、社内固有ホスト名など）がないか、必要に応じて `git log -p -n 20` や主要設定ファイルを確認し、誤検知（False Positive）のフィルタリングと文脈補完を行います。
- **重要**: コード作者を示す署名に記載されているメールアドレスや氏名を確認・検知した場合は、除外対象であるため**結果レポートには一切記載せず（言及もせず）無視**してください。
- ※追加で検出した機微情報がある場合も、必ず**先頭4文字＋`****`** のマスキングルールを適用してください。

### Step 3: ターミナルへのレポート出力
スクリプトが出力したMarkdownレポートおよびStep 2の精査結果を統合し、ターミナル（チャット応答）に直接出力します。
