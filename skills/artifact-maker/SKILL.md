# Artifact Generation Workflow

ユーザーが「まとめページにして」「Artifactとして」と要求した場合、標準出力（ターミナル）への長文回答を避け、以下の仕様に従って実体ファイルを生成してください。
なお、ブラウザで表示することを目的とするので、ファイルはHTML形式とする。
この時に、図を用いてできるだけ視覚的に情報をまとめる。

1. **保存先の決定:**
   プロジェクトルートの `.artifacts/` ディレクトリ内にファイルを生成すること。ディレクトリが存在しない場合は作成すること。
2. **ファイル名の決定:**
   ファイル名にはタイムスタンプやトピック名を含める（例: `20261114_db_comparison.md`）。
3. **出力の抑制と完了通知:**
   ファイルへの書き込み完了後、ターミナルには「生成したファイルのパス」と「内容の簡潔な要約（3行程度）」のみを出力し、全文は出力しないこと。
4. **出力結果の表示:**
   出力したファイルを標準ブラウザで起動する。
